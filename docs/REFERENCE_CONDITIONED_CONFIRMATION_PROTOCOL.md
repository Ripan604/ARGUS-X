# Reference-conditioned guided-wave fundamentals experiment

8 October 2026. This protocol is fixed before the new confirmation waveform
results. It follows a failed initial measured localization model and is an
engineering development iteration, not a claim of an externally preregistered
invention or unseen specimen generalization.

## Technical change

The experimental chain separates source timing, healthy propagation drift and
possible structural discrepancy. Healthy-only temperature anchors estimate a
bounded receiver stretch/delay/gain model. The observed electrical source pitch
aligns the clock of an acquired path. A test receiver waveform cannot fit its own
reference warp. Per-path healthy residual uncertainty can temper spatial evidence
and normalize the adaptive predictive-disagreement criterion. A separately
calibrated complete-trajectory gate compares discrepancy to healthy executions
of the same frozen controller before any anomaly is supported.

This directly addresses observed healthy false alarms and state-dependent
acquisition. Baseline stretch, source correlation, heteroscedastic inference and
conformal ranks are established methods; the candidate engineering subject is
their ordered, reference-qualified interaction with acquisition and replanning.
Novelty/inventive step remains a professional review question.

## Data roles and blinding

Fit transport only from original healthy first-cycle warming banks at nominal
20/40/60 C, using actual surface readings and recorded source pitches. The
healthy 40 C leave-middle-out development check estimates a residual proxy from
20/60 C interpolation, with fixed floor 0.02. Final fitting can use all three
anchors. These fit references are not independent physical noise estimates.

The new acquisition plan reserves 19 healthy first-cycle cooling blocks
(22..58 C, step 2) for trajectory calibration, and separate 30/50 C warming banks
for confirmation: two healthy second-cycle banks and eight reference-mass banks.
No confirmation receiver waveform can fit transport, reference scales, policy,
alpha, score or threshold. A full comparison must wait for all 29 original
members to arrive with verified provenance. Missing data is never synthesized.

If the repository cannot supply those banks, only an explicitly labelled
development reanalysis of the original 18 banks may be run. The previous
positions and results were already seen. Such a reanalysis is exploratory;
it cannot be relabelled as fresh confirmation. The healthy-only fit remains
a useful metrology-development result even without confirmation captures.

## Prespecified model and controls

Keep the native 40 kHz/10 MHz recorded windows, 66 actual unordered pairs,
50 by 50 full-panel grid and beta=1.05 spatial kernel. A whole location is held
out of the spatial fit, including all its development temperatures. The source
pitch and temperature of a selected test path are observable acquisition data;
unselected test pitches and receivers remain hidden from path selection.

Compare raw-global, transported-global and transported-heteroscedastic response
models on a shared path set qualified by healthy-anchor support. Unsupported
source/temperature observations consume their opportunity but cannot update
location or pass the gate. Qualified-path shortages remain explicit failures.

For heteroscedastic inference, the squared residual mean of the training spatial
model is added to the independently fitted healthy path scale squared, with
floor 0.02. The adaptive criterion is predictive response variance divided by
that declared observation variance. This is a disagreement proxy, not exact
information gain. A learned spatial response is not a defect-existence model.

The first healthy-only fit qualified zero paths under a 1% stretch domain.
Its exact failed source and report are preserved. A 5% physically bounded
development revision keeps all fit/source/identifiability qualification
thresholds and qualifies 20 paths. Before confirmation analysis, freeze the
largest stated checkpoint below that number: horizon 16. Every variant uses
those same 20 feasible paths, rather than executing unsupported references.

Use adaptive, geometry-spread and 16 fixed seeded-random policies with budgets
1/2/4/8/12/16 and seed 20261008. Keep every failed opportunity, conditional
location error, source/transport rejection, class weight and query count. No
parameter is selected by confirmation label accuracy.

## Gate and control disposition

Calibrate one maximum checkpoint mean squared standardized discrepancy per
complete healthy controller execution. Binding hashes join the exact model,
controller, reference and protocol. A new prefix is compared conservatively
using `(1 + calibration maxima >= prefix score) / (N+1)`. A rejected reference,
model mismatch, reused artifact, incomplete trace or fewer than 19 blocks
withholds the fixed 5% decision.

The required feedback is explicit: unsupported evidence requests qualified
reference acquisition/recalibration; supported anomaly requests an independent
verification; background-consistent evidence can continue within budget.
There is no automatic healthy structural release or actuator command.
The fixed maximum across complete trajectories accounts for all stated looks,
subject to exchangeability assumptions. Cooling versus warming and one-specimen
dependence leave those assumptions unverified; no field 95% certificate follows.

## Evidence boundary

Report healthy reference prediction separately from conditional location and
operational anomaly decisions. Gate refusal is not detection accuracy. Report
calibration cost and count as whole blocks, not the number of paths. Preserve
all old reports and source versions. Experimental modules remain separate from
the production audio-range physical session until independently validated.
